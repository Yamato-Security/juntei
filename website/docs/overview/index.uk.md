# Про Juntei { #about-juntei }

Juntei — це парсер криміналістичних артефактів Windows, написаний мовою Rust із безпечною роботою з пам'яттю. Він доповнює
[Hayabusa](https://github.com/Yamato-Security/hayabusa): Hayabusa аналізує журнали подій Windows,
тоді як Juntei розбирає постійні артефакти файлової системи, реєстру, виконання, активності користувача, використання ресурсів
і засобів захисту.

Той самий виконуваний файл працює у Windows, macOS і Linux. Це зручно, коли аналітик отримує зібрані офлайн-дані KAPE,
Velociraptor, образ диска чи інші дані і хоче мати один узгоджений інтерфейс замість
окремої програми для кожного артефакту.

## Цілі проєктування { #design-goals }

- **Обґрунтований розбір:** зберігати необроблені значення та повідомляти про пошкодження, а не мовчки вигадувати дані.
- **Корисність для всіх:** використання за замовчуванням має бути простим для початківців, але водночас гнучким і повнофункціональним
  для досвідчених фахівців.
- **Автономний виконуваний файл:** для роботи не потрібні жодні бібліотеки середовища виконання. Він просто працює
  одразу після завантаження.
- **Надзвичайна швидкість:** мета — бути найшвидшим парсером і водночас не потребувати великого обсягу
  пам'яті.
- **Кросплатформне використання:** аналіз доказів Windows без потреби в робочій станції Windows.
- **Автоматизація:** CSV для електронних таблиць і засобів побудови часових шкал; JSON/JSONL для `jq`, скриптів і озер даних.
- **Безпечна обробка збоїв:** пошкоджені записи, коли це можливо, позначаються в звіті та пропускаються.
- **Прозоре походження:** Juntei зазначає парсери з відкритим кодом і довідкові інструменти, на яких ґрунтується кожна реалізація.

## Чого Juntei не робить { #what-juntei-does-not-do }

Juntei не знімає дані з живого диска, не монтує криміналістичні образи і не замінює процедури збереження доказів. Він
не об'єднує автоматично всі артефакти в єдину картину інциденту. Він розбирає
надані вами докази та створює записи, придатні для розслідування та зіставлення.

Juntei також не виконає аналіз замість вас. Для аналізу доказів потрібен фахівець з DFIR.
