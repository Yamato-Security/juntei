# Juntei အကြောင်း { #about-juntei }

Juntei သည် memory-safe ဖြစ်သော Rust ဖြင့် ရေးသားထားသည့် Windows forensic အထောက်အထား parser တစ်ခု ဖြစ်သည်။ ၎င်းသည်
[Hayabusa](https://github.com/Yamato-Security/hayabusa) ကို ဖြည့်စွက်ပေးသည်- Hayabusa က Windows event log များကို
ခွဲခြမ်းစိတ်ဖြာပြီး Juntei က ဖိုင်စနစ်၊ registry၊ လုပ်ဆောင်မှု၊ အသုံးပြုသူ လှုပ်ရှားမှု၊ resource အသုံးပြုမှုနှင့်
လုံခြုံရေးထုတ်ကုန်တို့၏ ကြာရှည်တည်ရှိသော အထောက်အထားများကို ခွဲခြမ်းစိတ်ဖြာသည်။

တူညီသော binary ကို Windows၊ macOS နှင့် Linux ပေါ်တွင် အသုံးပြုနိုင်သည်။ Artifact တစ်မျိုးစီအတွက် program သီးသန့်အစား interface တစ်ခုတည်းဖြင့် စုဆောင်းထားသော Windows အထောက်အထားများနှင့် disk image များကို စစ်ဆေးနိုင်သည်။

## ဒီဇိုင်း ပန်းတိုင်များ { #design-goals }

- **ခုခံကာကွယ်နိုင်သော ခွဲခြမ်းစိတ်ဖြာမှု:** ဒေတာကို တိတ်တဆိတ် တီထွင်ဖန်တီးမည့်အစား raw တန်ဖိုးများကို ထိန်းသိမ်းပြီး ပျက်စီးမှုကို အစီရင်ခံသည်။
- **လူတိုင်းအတွက် အသုံးဝင်ခြင်း:** ပုံသေအသုံးပြုပုံသည် စတင်လေ့လာသူများအတွက် အသုံးပြုရလွယ်ကူရမည်ဖြစ်ပြီး
  ကျွမ်းကျင်သူများအတွက်လည်း စိတ်ကြိုက်ပြင်ဆင်နိုင်ကာ လုပ်ဆောင်ချက် ပြည့်စုံရမည်။
- **သီးခြားရပ်တည်နိုင်သော binary:** လုပ်ဆောင်ရန် မည်သည့် runtime library မျှ မလိုအပ်ပါ။ ချက်ချင်း
  အသုံးပြုနိုင်သည်။
- **အလွန်မြန်ဆန်ခြင်း:** memory ပမာဏ များစွာ မလိုအပ်ဘဲ အမြန်ဆုံး parser ဖြစ်ရန် ရည်ရွယ်သည်။
- **Platform ဖြတ်ကျော် အသုံးပြုနိုင်ခြင်း:** Windows workstation မလိုအပ်ဘဲ Windows အထောက်အထားများကို ခွဲခြမ်းစိတ်ဖြာနိုင်သည်။
- **အလိုအလျောက်လုပ်ဆောင်ခြင်း:** spreadsheet နှင့် timeline tool များအတွက် CSV၊ `jq`၊ script များနှင့် data lake များအတွက် JSON/JSONL။
- **ဘေးကင်းစွာ မအောင်မြင်ခြင်း:** ပုံစံမမှန်သော မှတ်တမ်းများကို ဖြစ်နိုင်သမျှ အစီရင်ခံပြီး ကျော်သွားသည်။
- **ပွင့်လင်းမြင်သာသော မူလအရင်းအမြစ်:** Juntei သည် implementation တစ်ခုစီ၏ နောက်ကွယ်ရှိ open-source parser များနှင့် ကိုးကား tool များကို ဖော်ပြသည်။

## Juntei မလုပ်ဆောင်သည့်အရာများ { #what-juntei-does-not-do }

Juntei သည် live disk ကို ရယူခြင်း သို့မဟုတ် အထောက်အထား ထိန်းသိမ်းခြင်းကို အစားထိုးခြင်း မပြုပါ။ ၎င်း mount လုပ်သော
disk image များမှာ VHDX နှင့် E01 image များသာ ဖြစ်ပြီး read-only အဖြစ်သာ mount လုပ်ပါသည်။ အထောက်အထားအားလုံးကို incident ဇာတ်ကြောင်းတစ်ခုတည်းအဖြစ် အလိုအလျောက် ပေါင်းစပ်ပေးခြင်း မပြုပါ။
၎င်းသည် သင်ပေးသော အထောက်အထားများကို ခွဲခြမ်းစိတ်ဖြာပြီး စုံစမ်းစစ်ဆေးမှုနှင့် ချိတ်ဆက်စစ်ဆေးမှုအတွက် သင့်လျော်သော
မှတ်တမ်းများကို ထုတ်ပေးသည်။

Juntei သည် သင့်ကိုယ်စား ခွဲခြမ်းစိတ်ဖြာမှုကိုလည်း ပြုလုပ်ပေးမည် မဟုတ်ပါ။ အထောက်အထားများအပေါ် ခွဲခြမ်းစိတ်ဖြာမှု ပြုလုပ်ရန် DFIR ကျွမ်းကျင်သူ လိုအပ်သည်။
