## စုဆောင်းမှု အမျိုးအစားများ { #collection-types }

Juntei သည် `-f` ဖြင့် အထောက်အထားတစ်ခုတည်းကို လက်ခံသည်၊ သို့မဟုတ် `-d` ဖြင့် စုဆောင်းမှုတစ်ခုကို recursive ရှာဖွေသည်။
Directory mode ကို host တစ်ခုစီတွင် `C/Windows/System32/config/SYSTEM` သို့မဟုတ် `C/Users/alice/NTUSER.DAT` ကဲ့သို့သော
path များ ပါဝင်သည့် ဘုံ triage layout များအတွက် ဒီဇိုင်းထုတ်ထားသည်။

ကူးယူထားသော registry သို့မဟုတ် ESE database များကို ခွဲခြမ်းစိတ်ဖြာခြင်းမပြုမီ [အထောက်အထား စုဆောင်းခြင်း](../getting-started/collection.md) ကို ကြည့်ပါ-
Windows မြင်ခဲ့သော အခြေအနေကို ပြန်လည်တည်ဆောက်ရန် ဆက်စပ် transaction log များသည် မရှိမဖြစ် လိုအပ်နိုင်သည်။
