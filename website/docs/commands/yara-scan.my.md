# YARA စစ်ဆေးမှု { #yara-scan }

စုဆောင်းထားသောဖိုင်များကို သယ်ဆောင်သုံးနိုင်သော Rust အင်ဂျင်ဖြင့် စစ်ဆေးသည်။ Windows၊ macOS နှင့် Linux ကို ပံ့ပိုးသည်။ ဖိုင်များကို ဒေတာအဖြစ်သာ ဖတ်ပြီး လုံးဝမလုပ်ဆောင်ပါ။ အလိုအလျောက် အထောက်အထားခွဲခြမ်းခြင်းနှင့် သီးခြား command ဖြစ်သည်။

## စည်းမျဉ်းများ ရွေးချယ်ခြင်း { #choose-rules }

ပုံမှန် Core သည် တိကျမှုနှင့် စွမ်းဆောင်ရည်ကို ဦးစားပေးသည်။ Extended သည် ရှာဖွေမှုကို ချဲ့ထွင်သည်။ Full သည် အကျယ်ပြန့်ဆုံးဖြစ်သော်လည်း မှားယွင်းသတိပေးချက်များ ပိုများနိုင်သည်။

```bash
juntei yara-scan -d evidence/ -o yara-core/
juntei yara-scan -d evidence/ --ruleset extended -o yara-extended/
juntei yara-scan -d evidence/ --ruleset full -o yara-full/ -t jsonl
juntei yara-scan -d evidence/ --rules local-rules/ -o yara-offline/
```

`--rules <FILE_OR_DIRECTORY>`: ဒေါင်းလုဒ်မလုပ်ဘဲ ဒေသတွင်း UTF-8 စည်းမျဉ်းဖိုင် သို့မဟုတ် directory ကို သုံးသည်။ Directory များကို အဆင့်ဆင့်ရှာသည်။ Include များသည် ရွေးထားသော စည်းမျဉ်း directory အတွင်းသာရှိပြီး မှီခိုမှုအစဉ်အတိုင်း တစ်ကြိမ်သာ ဖြန့်သည်။ မမှန်ကန်သော သို့မဟုတ် မပံ့ပိုးသော စည်းမျဉ်းများကို တိတ်တဆိတ်မဖယ်ဘဲ compilation ကို ရပ်သည်။

## ကန့်သတ်ချက်နှင့် အတိုင်းအတာ { #limits-and-scope }

Quarantine မှ ပြန်ထုတ်ထားသော payload များအပါအဝင် ပုံမှန်ဖိုင်အားလုံးကို စစ်ဆေးနိုင်သည်။ Symbolic link နှင့် အထူးဖိုင်များကို ကျော်သည်။ Archive နှင့် disk image များကို မဖြည်သလို အသုံးပြုနေသော memory ကိုလည်း မစစ်ဆေးပါ။ တည်ငြိမ်သော ထုတ်ယူပြီးဖိုင်များနှင့် အထောက်အထားအပြင်ဘက်ရှိ output directory အသစ်ကို သုံးပါ။

- `-T, --threads <N>`: တစ်ပြိုင်တည်း စစ်ဆေးမှုအရေအတွက်။ ပုံမှန် CPU အရေအတွက်ဖြစ်ပြီး အများဆုံး 8 ဖြစ်သည်။
- `--timeout <SECONDS>`: ဖိုင်တစ်ဖိုင်စီ အကဲဖြတ်ချိန်ကန့်သတ်ချက် စက္ကန့်။ ပုံမှန် 60 ဖြစ်သည်။
- `--max-file-mib <MIB>`: ဖိုင်အများဆုံးအရွယ်အစား MiB။ ပုံမှန် 64 ဖြစ်သည်။ ပိုကြီးသောဖိုင်များကို ကျော်ထားကြောင်း မှတ်တမ်းတင်သည်။ Worker နှင့် buffer ပိုများလျှင် memory ပိုသုံးသည်။
- `--rules-release YYYYMMDD`: Forge ထုတ်ဝေရက် သို့မဟုတ် ပုံမှန် latest။ ပြန်လည်စမ်းသပ်နိုင်ရန် ရရှိသော source နှင့် hash များကို သိမ်းသည်။

## ရလဒ်များ { #results }

- `YaraDetections.csv` / `YaraDetections.jsonl`: စည်းမျဉ်းနှင့် ဖိုင်ကိုက်ညီမှုများ၊ relative path၊ မူရင်းကွန်ပျူတာအမည်၊ hash၊ metadata နှင့် ကန့်သတ်ထားသော ကိုက်ညီရာနေရာများ ပါဝင်သည်။ ကိုက်ညီသော byte များကို မထုတ်ပေးပါ။
- `YaraFiles.csv` / `YaraFiles.jsonl`: ကျော်ထားမှု၊ ဖတ်ရှုမှုအမှား၊ အချိန်ကုန်ဆုံးမှုနှင့် တစ်စိတ်တစ်ပိုင်းရလဒ်များပါဝင်သော ဖိုင်တစ်ဖိုင်စီ စစ်ဆေးမှုအခြေအနေ။
- `Summary.json`: ပြီးစီးမှုအခြေအနေ၊ ဆက်တင်၊ အရေအတွက်၊ အင်ဂျင်ဗားရှင်းနှင့် source hash များ။
- `Rules.yar`: ဒေါင်းလုဒ်ရရှိသော မူရင်းစည်းမျဉ်းများ သို့မဟုတ် include ဖြန့်ပြီး ဒေသတွင်းစည်းမျဉ်း snapshot။
- `CompilationWarnings.txt` / `CompilationError.txt`: Compilation သတိပေးချက်များ သို့မဟုတ် compilation မအောင်မြင်သည့်အမှား။

Exit code 0 သည် ပြီးစီးမှု၊ 3 သည် မပြည့်စုံသောစစ်ဆေးမှု၊ 2 သည် ပြင်ဆင်မှု/ထုတ်ပေးမှုအမှား၊ 130 သည် ပယ်ဖျက်မှုဖြစ်သည်။ ကိုက်ညီမှုသည် စုံစမ်းရန်အချက်သာဖြစ်ပြီး ချိုးဖောက်ခံရကြောင်း သက်သေမဟုတ်ပါ။ ကိုက်ညီမှုမရှိခြင်းသည်လည်း လုံခြုံကြောင်းမဆိုလိုပါ။ စည်းမျဉ်းခေါင်းစဉ်နှင့် အထောက်အထားနောက်ခံကို စစ်ပါ။ Quarantine payload ကို အမျိုးအစားခွဲမီ decrypt လုပ်ပါ။
