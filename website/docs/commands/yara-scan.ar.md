# فحص YARA { #yara-scan }

فحص الملفات المجمعة باستخدام محرك Rust قابل للنقل. يدعم Windows وmacOS وLinux. تُقرأ الملفات كبيانات ولا تُنفذ مطلقاً. هذا الأمر مستقل عن التحليل التلقائي للآثار الجنائية.

## اختيار القواعد { #choose-rules }

Core هو الخيار الافتراضي ويركز على الدقة والأداء. يوسع Extended نطاق البحث. يوفر Full أوسع تغطية، لكنه قد ينتج إنذارات كاذبة أكثر.

```bash
juntei yara-scan -d evidence/ -o yara-core/
juntei yara-scan -d evidence/ --ruleset extended -o yara-extended/
juntei yara-scan -d evidence/ --ruleset full -o yara-full/ -t jsonl
juntei yara-scan -d evidence/ --rules local-rules/ -o yara-offline/
```

`--rules <FILE_OR_DIRECTORY>`: استخدام ملف قواعد UTF-8 أو مجلد محلي دون تنزيل. يجري البحث في المجلدات تكرارياً. تبقى التضمينات ضمن مجلد القواعد المحدد وتُوسع مرة واحدة حسب ترتيب الاعتماد. القواعد غير الصالحة أو غير المدعومة توقف الترجمة بدلاً من إسقاطها بصمت.

## الحدود والنطاق { #limits-and-scope }

يشمل الفحص جميع الملفات العادية، ومنها المحتويات المستعادة من العزل. تُتخطى الروابط الرمزية والملفات الخاصة. لا تُفك الأرشيفات أو صور الأقراص ولا تُفحص الذاكرة الحية. استخدم ملفات مستخرجة مستقرة ومجلد إخراج جديداً خارج الأدلة.

- `-T, --threads <N>`: عدد عمليات الفحص المتوازية؛ الافتراضي عدد وحدات CPU بحد أقصى 8.
- `--timeout <SECONDS>`: مهلة تقييم كل ملف بالثواني؛ الافتراضي 60.
- `--max-file-mib <MIB>`: أقصى حجم للملف بوحدة MiB؛ الافتراضي 64. تُسجل الملفات الأكبر كمتخطاة. زيادة العاملين وأحجام المخازن تزيد استهلاك الذاكرة.
- `--rules-release YYYYMMDD`: تاريخ إصدار Forge أو latest افتراضياً. تُحفظ المصادر المنزلة وبصماتها لإعادة إنتاج الفحص.

## النتائج { #results }

- `YaraDetections.csv` / `YaraDetections.jsonl`: تطابقات القواعد والملفات، مع المسارات النسبية وأسماء أجهزة الأدلة والبصمات والبيانات الوصفية ومواضع تطابق محدودة. لا تُصدر البايتات المطابقة.
- `YaraFiles.csv` / `YaraFiles.jsonl`: تغطية كل ملف، بما فيها التخطي وأخطاء القراءة وانتهاء المهلة والنتائج الجزئية.
- `Summary.json`: حالة الإكمال والإعدادات والأعداد وإصدار المحرك وبصمات المصادر.
- `Rules.yar`: القواعد المنزلة كما هي، أو لقطة من القواعد المحلية بعد توسيع التضمينات.
- `CompilationWarnings.txt` / `CompilationError.txt`: تحذيرات الترجمة أو خطأ عند فشلها.

رموز الخروج: 0 للإكمال، و3 للتغطية الناقصة، و2 لفشل الإعداد أو الإخراج، و130 للإلغاء. التطابق خيط للتحقيق وليس إثباتاً للاختراق؛ وعدم التطابق لا يثبت الأمان. راجع عنوان القاعدة وسياق الأثر. يجب فك تشفير محتوى العزل قبل التعرف عليه.
