# การสแกน YARA { #yara-scan }

สแกนไฟล์ที่เก็บรวบรวมด้วยเอนจิน Rust แบบพกพา รองรับ Windows, macOS และ Linux อ่านไฟล์เป็นข้อมูลเท่านั้นและไม่เรียกใช้ไฟล์ คำสั่งนี้แยกจากการแยกวิเคราะห์อาร์ติแฟกต์อัตโนมัติ

## เลือกกฎ { #choose-rules }

Core เป็นค่าเริ่มต้น โดยเน้นความแม่นยำและประสิทธิภาพ Extended ขยายขอบเขตการค้นหา Full ครอบคลุมมากที่สุด แต่อาจมีผลบวกลวงเพิ่มขึ้น

```bash
juntei yara-scan -d evidence/ -o yara-core/
juntei yara-scan -d evidence/ --ruleset extended -o yara-extended/
juntei yara-scan -d evidence/ --ruleset full -o yara-full/ -t jsonl
juntei yara-scan -d evidence/ --rules local-rules/ -o yara-offline/
```

`--rules <FILE_OR_DIRECTORY>`: ใช้ไฟล์หรือไดเรกทอรีกฎ UTF-8 ภายในเครื่องโดยไม่ดาวน์โหลด ค้นหาไดเรกทอรีย่อยแบบเรียกซ้ำ include จำกัดอยู่ภายในไดเรกทอรีกฎที่เลือกและขยายเพียงครั้งเดียวตามลำดับการพึ่งพา กฎที่ไม่ถูกต้องหรือไม่รองรับจะหยุดการคอมไพล์ ไม่ถูกละทิ้งเงียบ ๆ

## ข้อจำกัดและขอบเขต { #limits-and-scope }

รองรับไฟล์ปกติทั้งหมด รวมถึงเพย์โหลดที่กู้คืนจากการกักกัน ข้ามลิงก์สัญลักษณ์และไฟล์พิเศษ ไม่แตกไฟล์บีบอัดหรืออิมเมจดิสก์ และไม่สแกนหน่วยความจำสด ใช้ไฟล์ที่สกัดแล้วซึ่งคงที่และไดเรกทอรีผลลัพธ์ใหม่ภายนอกหลักฐาน

- `-T, --threads <N>`: จำนวนการสแกนพร้อมกัน ค่าเริ่มต้นเท่ากับจำนวน CPU แต่ไม่เกิน 8
- `--timeout <SECONDS>`: เวลาประเมินสูงสุดต่อไฟล์เป็นวินาที ค่าเริ่มต้น 60
- `--max-file-mib <MIB>`: ขนาดไฟล์สูงสุดเป็น MiB ค่าเริ่มต้น 64 ไฟล์ที่ใหญ่กว่าจะถูกบันทึกว่าข้าม การเพิ่มเวิร์กเกอร์และบัฟเฟอร์ทำให้ใช้หน่วยความจำมากขึ้น
- `--rules-release YYYYMMDD`: วันที่เผยแพร่ Forge หรือค่าเริ่มต้น latest บันทึกต้นฉบับและแฮชที่ดาวน์โหลดไว้เพื่อทำซ้ำ

## ผลลัพธ์ { #results }

- `YaraDetections.csv` / `YaraDetections.jsonl`: การจับคู่กฎกับไฟล์ พร้อมพาธสัมพัทธ์ ชื่อคอมพิวเตอร์ต้นทาง แฮช เมทาดาทา และตำแหน่งที่ตรงกันจำนวนจำกัด ไม่ส่งออกไบต์ที่ตรงกัน
- `YaraFiles.csv` / `YaraFiles.jsonl`: ความครอบคลุมรายไฟล์ รวมถึงการข้าม ข้อผิดพลาดการอ่าน หมดเวลา และผลลัพธ์บางส่วน
- `Summary.json`: สถานะสิ้นสุด การตั้งค่า จำนวน เวอร์ชันเอนจิน และแฮชต้นฉบับ
- `Rules.yar`: กฎต้นฉบับที่ดาวน์โหลด หรือสแนปช็อตกฎภายในเครื่องที่ขยาย include แล้ว
- `CompilationWarnings.txt` / `CompilationError.txt`: คำเตือนการคอมไพล์ หรือข้อผิดพลาดเมื่อคอมไพล์ไม่สำเร็จ

รหัสออก: 0 คือเสร็จสมบูรณ์ 3 คือความครอบคลุมไม่ครบ 2 คือการตั้งค่า/เอาต์พุตล้มเหลว และ 130 คือยกเลิก การตรงกับกฎเป็นเบาะแส ไม่ใช่ข้อพิสูจน์ว่าถูกบุกรุก และการไม่ตรงก็ไม่ยืนยันความปลอดภัย ตรวจชื่อกฎกับบริบทของอาร์ติแฟกต์ ต้องถอดรหัสข้อมูลกักกันก่อนระบุเพย์โหลด

## การจับคู่ MFT และกู้คืน { #mft-recovery }

สแกน MFT เป็นไบต์ดิบทีละไฟล์ด้วยขนาดจำกัดแยกต่างหาก (ค่าเริ่มต้น 512 MiB) แยกวิเคราะห์เรคคอร์ดที่ตำแหน่งจับคู่แล้วสแกนสตรีม DATA แบบ resident อีกครั้งโดยอิสระ กู้คืนเฉพาะสตรีมที่ตรงกับกฎด้วยตัวเอง การจับคู่เมทาดาทา ข้ามเรคคอร์ด หรือข้อมูล nonresident จะถูกรายงานโดยไม่ส่งออกเนื้อหาไฟล์

`--max-mft-mib <MIB>` · `--max-mft-recoveries <N>`

ค่าเริ่มต้นกู้คืนได้ไม่เกิน 1000 สตรีมต่อการทำงาน แสดงข้อจำกัด เรคคอร์ดเสียหาย และหมดเวลาอย่างชัดเจน ชื่อที่บันทึกใช้นามสกุลกักกัน และไม่สร้างโครงสร้างไดเรกทอรีหลักฐานขึ้นใหม่

`YaraMFTResults.csv` / `YaraMFTResults.jsonl` · `RecoveredMFT/` · `.quarantined`
