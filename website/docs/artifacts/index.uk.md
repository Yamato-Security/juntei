# Посібник з артефактів { #artifact-guide }

Windows зберігає сліди, що перетинаються, у файловій системі, реєстрі, базах даних сумісності,
історії інтерфейсу користувача, обліку ресурсів і засобах захисту. Juntei розбирає ці джерела,
але слідчий однаково має самостійно інтерпретувати, що означає кожне джерело.

## Читайте застереження перед полями { #read-warnings-before-fields }

Кожна сторінка артефакту має однакову послідовність:

1. **Що це таке** і на які запитання він може відповісти.
2. **Де його знайти** і як збирання на нього впливає.
3. **Що він доводить — і чого не доводить.**
4. **Як його розібрати** за допомогою Juntei.
5. **Як читати кожне поле виводу.**
6. **Як зіставляти його** з незалежними доказами.
7. **Додаткові відомості** для низькорівневого дослідження.

!!! danger "Не ототожнюйте результат парсера зі шкідливістю"
    Результати Juntei вказують на закономірності, які варто перевірити, як-от ім'я системного двійкового файлу поза
    `System32`. Інсталятори, адміністратори, рівні сумісності та оновлення програмного забезпечення можуть створювати
    незвичні записи. Перевіряйте з урахуванням контексту та незалежних доказів.
