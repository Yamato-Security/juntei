# دليل الآثار الرقمية { #artifact-guide }

يحتفظ Windows بآثار متداخلة في نظام الملفات، وسجل Windows، وقواعد بيانات التوافق، وسجل واجهة
المستخدم، ومحاسبة الموارد، ومنتجات الأمان. يحلل Juntei هذه المصادر، لكن يبقى على المحقق أن يفسّر ما
يعنيه كل مصدر.

## اقرأ التحذيرات قبل الحقول { #read-warnings-before-fields }

تتبع كل صفحة من صفحات الآثار الرقمية التسلسل نفسه:

1. **ما هو الأثر** والأسئلة التي يمكنه الإجابة عنها.
2. **أين تجده** وكيف يؤثر الجمع فيه.
3. **ما الذي يثبته—وما الذي لا يثبته.**
4. **كيف تحلله** باستخدام Juntei.
5. **كيف تقرأ كل حقل من حقول الإخراج.**
6. **كيف تربطه** بأدلة مستقلة.
7. **مزيد من التفاصيل** للبحث على المستوى المنخفض.

!!! danger "لا تساوِ نتيجة المحلل بالنية الخبيثة"
    تحدد نتائج Juntei أنماطًا تستحق المراجعة، مثل اسم ملف ثنائي للنظام خارج
    `System32`. فقد تُنتج برامج التثبيت والمسؤولون وطبقات التوافق وتحديثات البرامج سجلات غير
    مألوفة. تحقق من صحتها بالسياق وبأدلة مستقلة.
